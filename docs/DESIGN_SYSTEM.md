# Design system

Forest #123D32, beige #F3EBDD, off-white #FBF8F2, ink #202822, gold #B59463, rose #D7B4AE. Muted text uses darker accessible variants. Georgia display serif pairs with a system sans serif. Editorial italic headings, thin rules, large photographic crops, generous whitespace and restrained motion create an original inclusive identity.

Spacing: 4/8/12/16/24/32/48/64px. Controls: 44px comfortable targets, visible forest focus rings, labelled forms, semantic buttons, accessible dialogs, responsive grids and reduced-motion support. Desktop sidebar plus content; mobile top brand and compact bottom navigation. Home remains topic-led.

Topic surfaces: skincare pale sage/beige; hair warm stone portraits; training forest with high-contrast data; grooming warm neutral; smile cool cream; fragrance rose/espresso; photos gallery cream.

Clothing scope only: dark casual espresso/cream, old money forest/cream/gold, minimalist off-white/charcoal. All clothing tabs inherit variables. Theme is remembered locally, never tied to gender.

All photography is stock editorial inspiration. AI visualization is an explicitly labelled placeholder, never progress. Shared focus, buttons, tabs, cards, fields, notices, empty states and modal components unify the app.
