# CHARETT second version

The owner's feedback supersedes the original Home-as-launchpad requirement. Home is now the For You feed. The original brief remains unchanged as a source record.

## Accepted requirements and review gates

| Requirement | Implementation and check |
| --- | --- |
| Understand the product on arrival | Compact introduction explaining style, self-care, progress, community and coach; first-visit browser review |
| Home is For You | Mixed photo/video feed, For You and Following, familiar likes/comments/private saves/linked-card sharing |
| Clear navigation | Home, Categories, AI Coach, My Plan, Messages; profile/avatar menu and public About us |
| Eight useful categories | Preserve every existing topic journey; explain each category's purpose and keep a beginner guide one click away |
| Fewer controls | No coach topic selector; optional post topic; search/refinement and detailed post metadata revealed on demand |
| Media formats | Feed images normalize to 1080 px wide and 1350–1920 px high; preserve proportions and offer framing; working video controls |
| Privacy | Public/private account choice, independent journal audiences defaulting to private, recipient access rechecked; private owner uploads never seeded or committed |
| Editorial visual direction | Preserve wordmark/fonts, increase forest-green/cream/rose surface contrast and photographic hierarchy; Victoria's Secret is inspiration only |
| Useful source content | Original beginner guides with explicit attachment/source mapping; distinguish reference claims from supported basics and personal preference |
| Honest demo | AI, accounts, ranking, shopping, visualizations and social activity stay labelled simulations; no paid service added |
| Verification | Check each implementation milestone, complete meaningful domain/browser regressions, inspect screenshots, compare published HTML and test the public URL without login |

## Source and visual limitations

The current cloud proxy blocks direct access to victoriassecret.com. No claim is made to have inspected its current website. Use the owner's description of image-led editorial composition and the agreed CHARETT palette; do not copy its assets or commercial layouts. Official medical pages may also be blocked: record actual access, use cautious general educational material, cite further reading and avoid presenting unchecked treatment claims as validated advice.

Raw reference PDFs, owner facts/photos/routines and secrets remain outside Git. The PDFs contain personal anecdotes, medication protocols and discriminatory aesthetic claims; these are not instructions for the product. Cosmetic preferences, routines and reference-comparison ideas can be rewritten inclusively; drug/dose protocols and unsupported results are not adopted.
